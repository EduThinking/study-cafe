# 스터디카페

개더타운 방식의 온라인 스터디카페입니다. 닉네임과 캐릭터를 정해 입장하고, 빈자리에 앉으면 공부 시간이 기록됩니다.

- 이동: 맵 클릭(터치) 또는 방향키·WASD
- 앉기 / 일어나기 / 키오스크: E
- 창 닫기: ESC
- 화상회의룸 A·B에 앉으면 같은 방 사람끼리 카메라·마이크로 대화

## 구성

- `index.html`, `style.css`, `game.js`: 앱 본체 (빌드 과정 없음)
- `config.js`: Supabase 주소와 공개용(publishable) 키
- `supabase 설정.sql`: Supabase SQL Editor에서 한 번 실행하는 설정
